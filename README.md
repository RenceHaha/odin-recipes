# Odin Recipes
A simple static recipe webpage built using HTML developed to guide users about "what" and "how" to cook a meal/dessert.

## Skills Demonstrated
Usage of HTML tags:
    `<heading>` - specific usage of `h1` `h2` `h3`.
    `<list>` - used `<ul>` to display the ingredients whilst `<ul>` for steps along with their respective children `<li>`.
    `<anchor>` - used `<a>` to navigate to deticated recipe pages.
